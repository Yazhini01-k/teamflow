# TeamFlow – Team Task Management System

TeamFlow is a web-based team collaboration and task management application designed to help teams organize projects, manage tasks, track progress, and collaborate efficiently.

## Project Overview

The application provides a centralized dashboard where users can manage their projects and tasks, monitor team activities, view deadlines, and receive notifications.

## Main Features

- User Login and Registration
- Dashboard
- Project Management
- Task Management
- Kanban Board
- Calendar
- Team Member Management
- Activity Tracking
- Notifications
- Profile and Settings

## Project Modules

### 1. Dashboard
Displays an overview of projects, tasks, task progress, and recent team activities.

### 2. Projects
Allows users to view and manage project details such as project name, description, status, progress, team members, and deadlines.

### 3. Tasks
Allows users to manage tasks with details such as task name, priority, status, assigned member, project, and due date.

### 4. Kanban Board
Provides a visual representation of tasks based on their current status:

- To Do
- In Progress
- Review
- Completed

### 5. Calendar
Displays project deadlines and task-related events in a calendar view.

### 6. Team Members
Displays team member information including name, email, role, department, and status.

### 7. Activity
Shows recent activities performed by team members, such as creating projects, updating tasks, and completing tasks.

### 8. Notifications
Displays important updates such as task assignments, project updates, completed tasks, and upcoming deadlines.

### 9. Settings
Allows users to manage profile and application preferences.
